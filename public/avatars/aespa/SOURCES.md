# aespa(에스파) 아바타 사진 출처

사용자가 직접 제공한 멤버별 얼굴 사진 한 장씩을 가운데 정사각으로 잘라 400px 로 맞춘 것.
어느 사진이 누구인지도 사용자가 지정했다. **로컬 대시보드 전용** — 재배포·상업적 사용 금지.
추가일: 2026-11-14.

| 파일 | 멤버 |
|---|---|
| karina.jpeg | 카리나 |
| winter.jpeg | 윈터 |
| giselle.jpeg | 지젤 |
| ningning.jpeg | 닝닝 |

표정 사진이 따로 없어 다섯 상태(대기·분석·구현·리뷰·완료) 모두 같은 사진을 쓴다.
원본 출처(기사·촬영처)는 받지 못했다.

## 성격(페르소나)

`src/lib/personas.ts`의 에스파 항목은 공개된 그룹 내 역할만 짧게 적었다.
호불호는 출처를 확인하지 못해 비워 뒀다.
